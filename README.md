## Yuecheng UAV Dataset

The Yuecheng UAV dataset is collected from RGB UAV orthoimagery over the Yuecheng area in Jincheng, Shanxi Province, China. It provides pixel-level semantic annotations for high-resolution remote sensing image segmentation.

The label maps contain one background label and six land-cover classes. The background label represents invalid or unlabeled regions and is excluded from semantic evaluation.

| Label ID | Land-cover class           |
| -------- | -------------------------- |
| 0        | Background / Ignore region |
| 1        | Agricultural land          |
| 2        | Building                   |
| 3        | Bare land                  |
| 4        | Road                       |
| 5        | Water                      |
| 6        | Vegetation                 |

Each pixel in the annotation map is assigned a label according to the corresponding land-cover category. The label IDs are consistent with the semantic classes listed above.
